# Adriatic_CEI_Supplementary_Materials
## Contents

### Supplementary Material A1 – QGIS workflow
The `A1_QGIS_Workflow` directory contains a detailed description of the
spatial-data processing workflow performed in QGIS, including vessel-density,
bathymetry, Natura 2000, analytical-grid, and CEI mapping procedures.

### Supplementary Material A2 – R scripts
The `A2_R_Scripts` directory contains the R scripts used for data preparation,
Composite Exposure Index (CEI) calculation, sensitivity analysis,
quartile-based hotspot classification, and preparation of figures and tables.
